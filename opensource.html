The open source version

PIM's source code is public, and this build is free — every feature unlocked, no trial, no purchase. It's the same app as the Play Store version with the billing code removed.

Download the APK

Hosted on GitHub · always the latest release

Already have PIM from Google Play? Uninstall it first, restart your phone, then install. The two builds are signed differently, so Android won't install one over the other. You'll have to set up your restricted apps again.

How to install it

  1. Tap the download button above on your phone, and open the APK file when it finishes.
  2. Android will warn you that your browser isn't allowed to install apps. Tap Settings in that prompt and turn on the permission for whichever app you downloaded with.
  3. Go back and tap Install.
  4. If Play Protect asks, choose Install anyway — it flags anything not downloaded from the Play Store.

Staying updated

Sideloaded apps don't update themselves. Either check back here now and then, or use Obtainium, a free app that watches GitHub releases and updates PIM automatically.

Why is it free?

The Play Store version is a one-time purchase, and that's what funds the work. If you use the free build and want to chip in anyway, there's a support page. Either way, the app is the same — nothing is held back.
